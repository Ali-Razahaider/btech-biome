# Biome | Vitality Mode 🌿

Biome is a high-performance, gamified sustainability platform designed to make eco-conscious living engaging and rewarding. 

## 🚀 Key Features
- **Vitality Mode**: A modern, light-themed interface designed for clarity and positive reinforcement.
- **Impact Hub**: Centralized dashboard to track your Eco-Score, Tier status, and daily streaks.
- **Carbon Audit**: Comprehensive calculator for transport, diet, and energy footprint.
- **Bio-Map**: Interactive, hyper-local environmental map with live AQI data.
- **Community Hub**: Join global challenges, compete on leaderboards, and collaborate with other guardians.

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **Data Viz**: Recharts
- **Mapping**: Leaflet.js
- **State**: Zustand

## 🏁 Getting Started

First, navigate to the frontend directory:

```bash
cd frontend/biome-app
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in the terminal) to view the application.

## 📁 Project Structure
- `/app`: Next.js App Router pages and layouts.
- `/components`: Reusable UI components including the Navigation and Map.
- `/store`: Zustand state management for user data and logic.
- `/lib`: Utility functions and helper classes.
- `/public`: Static assets and icons.
